# Changelog

All notable changes to this project will be documented in this file.

## [0.3.1] - 2026-08-09
- Refactored and reorganized system specifications and layout algorithm docs

## [0.3.0] - 2026-08-09
- Add auto-alignment solver, CSS margin/padding shorthand parser, dynamic layout margins, standard CSS property names styling, interactive showcase HTML gallery with modal fullscreen views, and optimized text-wrapping heights.

## [0.2.0] - 2026-08-08
- Add camelCase style color support (fillColor, strokeColor, fontColor) and CLI --version option

## [0.1.0] - 2026-08-08
- Initial release.
- Added colors and styles support (fillColor, strokeColor, fontColor).
